# 内容自动标题

## 范围与交互

任务、分支对话及新节点、灵感、项目记忆、定时任务在创建时不要求标题。空标题创建得到「新任务」「新对话」「新节点」「新分支」「新灵感」「新记忆」「新定时任务」等默认文案；描述、正文、工作树、Agent、时间等其它必要配置仍保留。项目、Agent、资源和 MCP 名称不在此范围。

首次有效内容随业务事务提交后，独立后台任务使用真实 `system_role=general` 的 Lumi 配置生成标题。用户发送不等待命名。空内容、继承的分支历史不触发命名；节点 Goal 的 objective 属于真实新内容。图和节点是独立标题目标，分别保留用户手改优先权。旧对象没有自动标题状态，不追溯命名。

已有标题始终可以手改，包括仍为默认名、运行中的对话和冻结历史节点。手改同值或改回默认文案也会撤销自动结果的写入权。仅保存正文、移动节点或更新执行状态不算手改标题。

## 持久任务与安全

不修改 SQLite 基线。每个目标使用 `app_metadata` 的 `auto_title:v1:<kind>:<id>` 保存独立的标题 epoch 和工作状态：`awaiting → queued → running → generated/failed/cancelled`，手改转 `manual`。首内容与入队同事务，模型调用在事务外。

后台 worker 独立于业务 Run/outbox 循环，使用持久租约与唯一 attempt token；完成时同时检查目标归属、存活、epoch、token 和租约。结果只窄更新标题，不写回旧正文或几何。最多两次尝试，总排队寿命三十分钟；跨崩溃不能保证模型恰好调用一次，但重复或迟到结果不能重复应用。手改、删除或服务关闭会取消活动调用。Lumi 未配置或不可用时保留默认名，不替换 Provider。

消息来源必须先插入，再在同一事务中登记命名意图；来源删除会撤销图和节点的旧命名结果。记忆归档在归档事务内持久取消未完成命名，恢复不复活旧任务；worker 已观察到的来源/目标删除同样持久取消并擦除种子，不只返回一个临时失活判断。

调用使用独立目录与 Provider 实例，保留 `ReadOnly` 沙箱；专用提示词明确要求只生成标题、不调用工具，即使原生工具可用也不得使用。按用户确认，后台命名不再要求严格 `DisableTools`，Codex 不会仅因缺少该能力被拒绝；这不是原生工具已被彻底关闭的保证。不注入 Skills、自定义 MCP、FileBridge、ToolBroker、Git 资源或 Computer Use，不共享用户原生会话。其它显式要求严格 NoTools 的既有业务保持原边界，不受此调整影响。只接受严格单字段 JSON 标题，拒绝非法、多行、过长、重复字段或危险格式的输出，不通过截断或提取第一行伪造成功。

只采用最新助手消息的最终文本；合法的空中间文本块仅清空该块，不提前否定后续答案。较新消息若只有推理或最终为空，不沿用较早消息的标题；工具和生命周期事件不能冒充助手文本或切换助手归属。

Runtime 对受控标题目录持有独占操作系统锁，启动时回收崩溃遗留的合法 attempt 目录；关闭时先等待原生任务退出，再清理和释放锁。清理使用根目录句柄，不跟随符号链接、不扫描用户 Provider 主目录。同根第二 Runtime 不能清理正在执行的任务，也不能绕过锁启动标题调用。

后台命名不创建用户助手会话、问答、Issue 评论或控制面 Run。首内容只保留有界种子，明显凭据内容保守跳过；启发式检查不能保证识别任意秘密。终态擦除种子。错误只保存类别，不记录原始种子、回答或 Provider 错误。真实标题变更按既有机制留下工作记录；项目记忆同时保存真实版本，不改写历史。

## Agent 绑定与画布

图可在没有 Agent 时创建为空图。根节点在节点内选择真实、已配置的 Agent 后初始化，不使用假 Agent 绕过非空外键。初始化并发只能产生一个真实根节点。

每个可写节点可独立切换 Agent；绑定和修订同事务更新，活跃 Run、未终态 Goal、冻结节点禁止切换。标题修改不受这一执行限制。历史 Run、审批、消息和继承快照不重写；新执行仍使用新的原生会话并重放公开历史。发送携带预期 Agent/修订并计入幂等意图，避免另一窗口切换后悄悄用不同 Agent 执行。

滚轮缩放采用有界对数目标、单事件和累计限幅、逐帧追赶，保留指针锚点；框内滚动不归画布。切图、复位、平移或销毁时取消剩余动画，不让旧动画写入新图。
