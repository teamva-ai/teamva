# 栏目首次教学

七个现有栏目分别在当前用户第一次进入时显示动画教学。教学真正显示后立即记录已看，
而不是等完成、关闭或跳过才记录。已看后，关闭、Esc、刷新、切项目、换窗口、换浏览器或
重启服务都不应再次自动显示同一栏目。显式回看可以重新显示教学，但不修改已看集合。

固定栏目 ID 与响应排序：

1. `overview`：概览
2. `issues`：任务
3. `conversations`：分支对话
4. `resources`：资源
5. `memories`：项目记忆
6. `schedules`：定时任务
7. `changes`：变更

## 与首次配置引导的边界

栏目教学不是首次配置引导的第三步。既有 onboarding 严格仍为「编程 CLI 检测 → 认识 Lumi」
两步；其 `needed`、`dismissed` 和设置中的重新打开行为完全不变。两个状态互不覆盖、互不重置。
栏目教学不创建项目、Agent 或业务内容，不执行模型调用。

## 动画与前端交互

- 复用公共 `Modal` 的焦点圈定、键盘操作、背景 inert 和嵌套栈。上部约三分之二为动画画面，下部说明用途、三步操作和「开始使用」。
- 七套独立内联 SVG 场景继承现有全局主题 token：总览、协作任务、聊天分叉、资源登记、项目约定、定时触发及只读 Git 差异。模拟光标三次平滑移动、停顿、点击和涟漪对应实际场景响应，11.2 秒循环，末尾渐隐复位。
- 演示使用内置示例，不发起业务 API、模型、文件写入、Git 修改或资源登记；不引入远程素材或 Lottie 运行依赖。弹窗不附加“不会操作真实数据”等免责式页脚。
- 教学弹窗打开即以11.2秒循环自动播放，回看也从头自动播放；提供手动暂停、继续和重播，文档隐藏时暂停，回到前台恢复，关闭后卸载。功能演示在自己的作用域内明确允许运动，不被系统低动态偏好默认暂停，也不被全局`0.01ms`/单次循环重置压缩；其他界面的低动态设置不变。
- 已看集合来自独立用户查询，不修改外观或语言保存版本。当前会话立即防重，写入回应乱序做单调合并；持久化失败保留提示，允许关闭并通过显式回看重试，不伪称保存成功。
- 首次配置覆盖层或业务弹窗拥有界面时延后展示，不消费未真正展示的教学。慢响应到达时仅展示当前栏目，不补弹已经离开的栏目。顶栏问号按钮允许随时回看。

## HTTP 契约

使用现有 Cookie 登录态与访问控制；写请求仍要求同源检查和 `X-CSRF-Token`，无匿名入口或新凭据。
所有成功响应沿用 `{ "data": ..., "meta": { "request_id": ... } }`，不提供设置版本锁。

- `GET /v1/me/feature-tours`
  - `data` 为 `{ "seen": [] }` 或包含已看 ID 的数组，始终按上述固定顺序。
  - 只读，不创建或回填元数据，不改任何业务数据；响应 `Cache-Control: no-store`。
- `POST /v1/me/feature-tours/{tour_id}/seen`，JSON body 必须是 `{}`。
  - 弹窗实际显示后标记一次，成功返回相同形状的完整已看集合。
  - 仅原子增加一个 ID；重复标记幂等，不改已有元数据时间，不推进 `UserPreferences.version`。
  - 多个窗口并发标记不同 ID 不会互相覆盖。
  - 未知 ID 返回 `400 invalid_argument`；不接受 `user_id`、项目、设备、版本或任意正文。
  - 没有重置、移除标记或产品自动修复接口。

前端只依据服务端状态决定是否自动展示，不用设备 TTL 或浏览器存储替代权威状态。
标记失败必须显示错误并保留失败状态，不能把本地缓存当作持久化成功。

## 持久化与隔离

使用既有 `app_metadata`，键为 `feature_tours:<user_id>`，值仅为已看的 true 标记，例如：

```json
{"overview":true,"issues":true}
```

无元数据等同空集合，GET 不落库。只在显式标记时创建记录；不改 SQL 基线、不迁移、不自动回填。
状态全局于用户，不按项目、窗口、浏览器或设备划分，也没有过期时间。

写事务首先执行限定有效用户的 `INSERT ... ON CONFLICT DO NOTHING`，在读取前取得 SQLite
写锁；校验原值后用 `json_set` 原子增加单个标记，事务提交后返回完整集合。
不存在或软删除的用户不能读写。HTTP 的用户 ID 仅来自认证上下文，无法指定其他用户。
外观、语言、原 onboarding 使用自己的记录，与栏目教学互不覆盖。

读取与写入均严格校验已有 JSON 对象，仅允许七个已知且不重复的键和 `true` 值。
结构错误、未知字段、false/null、重复键或无效 JSON 一律报错；写入失败回滚，绝不清空、覆盖或修复原值。
记录不含业务正文或秘密，不进入 Provider 环境。

## 自动化证据范围

Store/HTTP 测试覆盖空集合、全部七项、固定排序、重复幂等、独立连接并发合并、无效 ID、
坏元数据拒绝保留、失败回滚、用户隔离及删除、认证/CSRF、与外观及原引导的双向独立、同库重启持久化。
真实浏览器动画/弹窗生命周期及真实 Wails 验收应另行报告，不能以 API 测试代替。

普通浏览器业务回归通过 `scripts/e2e/feature-tour-test-setup.mjs` 显式标记测试用户已看全部栏目，避免遮挡原有业务流程；这不是产品跳过开关。首次进入验收必须用全新隔离数据目录和配套服务运行：

```bash
TEAMVA_TEST_UNSEEN_FEATURE_TOURS=1 \
TEAMVA_LOCAL_STATE_FILE="<新隔离服务的 runtime.json>" \
pnpm exec playwright test scripts/e2e/feature-tours.spec.mjs
```

该运行从原两步配置引导开始验证优先级，再逐一验证七栏目首次展示、刷新/新窗口不重复，以及桌面和移动端的自然时钟推进、光标真实几何位移、11.2秒无限循环、暂停重播、低动态环境下的自动播放、键盘与弹窗尺寸。自动播放验收不允许手动设置动画`currentTime`后冒充自然播放；普通完整浏览器套件保留首次进入专用用例为显式跳过，其余回看展示用例正常运行。
