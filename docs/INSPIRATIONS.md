# 全局灵感便利贴

## 使用

- 全局导航 `/inspirations` 与「工作记录」同区，不依赖当前项目才能使用。
- 按项目分区展示便利贴，包含「未分组」。每个区可新建，正文/标题可搜索，可筛选全部、未完成、已完成。
- 点击便利贴在右侧编辑；完成后保留在画板，以勾选、淡化和标题删除线区别，也能恢复未完成。保存/完成不改变便签的创建顺序。
- 右侧有「编辑」「灵感助手」标签，切换不丢编辑器和未发送问题状态；手机上是可关闭侧栏。
- 编辑器自动保存，支持手动保存、Cmd/Ctrl+S、源码模式和 `.md` 导出。切换便签、关闭面板或向助手提问前先保存；失败/冲突保留草稿，提供重读已保存版本的显式丢弃确认。

## 编辑器选择与存储边界

使用 MIT 许可的 [Milkdown Crepe 7.22.1](https://milkdown.dev/docs/guide/using-crepe)。它提供所见即所得 Markdown 编辑、标题、加粗/斜体、列表/任务列表、链接、引用、代码块和表格。

`inspirations.markdown` 是 **唯一正文，SQLite STRICT TEXT，最多 256 KiB UTF-8**。HTTP 接口只接受 Markdown 字符串，拒绝编辑器文档对象。编辑器内部 ProseMirror 树只存在于内存；保存只调用 `getMarkdown()`，不保存 `getJSON()` 或 HTML。标题、项目分组、完成状态等是普通元数据。编辑器可能规范化等价 Markdown 语法（如列表 `-` 序列化为 `*`），但不改变为编辑器私有文档格式。

所见即所得默认开启，源码模式可以直接查看/编辑真实 Markdown。导出为 `text/markdown`，没有 JSON 包装。暂不实现附件上传：关闭 Crepe 内置 AI、图片块上传和 LaTeX，禁止默认上传生成无法持久访问的 `blob:` 图片地址；可保留标准 Markdown 图片 URL。

## 所有权、记录与保存

- 灵感归属 `user_id`，`project_id` 只是可选分组，不是权限边界。仅可新关联当前用户的有效项目。
- 项目删除不连带删除灵感；已删除项目区仍保留便签，可以继续编辑或移到其他项目/未分组。
- 创建需要幂等键；更新/删除需要 `expected_version`，拒绝覆盖其他窗口更新。
- 每个编辑器只有一个串行保存队列。旧响应只确认对应的快照，不清除请求期间的新输入，也不改写另一个便签。
- 业务变更与工作记录通过 SQLite 触发器同事务提交；工作记录只保留 ID、标题、分组、版本和完成状态，**不复制 Markdown 正文**。
- 页面离开/刷新时对未保存内容提示；正文仍以服务端已保存版本为权威。

## 只读灵感助手

- 使用同一个不可删除的系统 Agent Lumi（可改名，如 Roomie）和其已保存的公共 Agent 配置。Lumi 不可删除并保持启用，可像普通 Agent 一样参与 Issue 和定时任务；灵感助手的只读限制只属于本入口的 Run 作用域。
- 灵感入口不提供配置表单，只链接到 `/agents?agent=<id>`。名称、备注、Provider、模型、提示词和 Skills 与普通 Agent 一样在 Agent 页显式保存；用户提示词和 Skills 实际传入灵感助手 Run，但不扩大该只读会话的授权。
- 全局会话增加 `scope=work_history|inspirations`，两个入口的会话列表分开；不创建假业务项目。
- 每轮传入选中灵感 ID 和当前查询条件，正文按需读取，不把编辑器内部 JSON 或整份便签列表塞进提示。
- `inspiration_list` 返回当前用户的分页便签摘要；`inspiration_get` 返回该用户便签的已保存 Markdown、版本、完成状态和链接。
- 复用原来的只读 Run、专属 home、文件桥、持久化 outbox、SSE、停止和恢复。ToolService 从持久化 Run 授权，**不给助手新增写入、删除、完成便签或修改项目的工具**。
- Crepe 自带的第三方 AI 模块未启用，浏览器不接收 Provider 密钥、不直接调用模型。
