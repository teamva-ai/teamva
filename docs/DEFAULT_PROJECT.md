# 默认项目「默认项目」

## 产品行为

- 本机有一个真实、持久化的默认项目，名称固定为 **默认项目**，在项目列表中置顶并显示「默认」标记。
- 默认项目不能删除或改名；说明仍可编辑。所有项目均不提供配色设置，统一使用全局外观。普通项目即使使用相同名称，也不因此被保护。
- 新打开的工作台窗口没有显式项目选择时，默认进入该项目。当前窗口手动切换后，刷新保留该窗口的选择；新窗口不读取旧 localStorage 中的项目 ID。明确的 `?project=<id>` 深链和对象导航继续按原有守卫切换。
- 删除当前普通项目后回到默认项目，不进入空项目状态。
- 默认项目不是空字符串或客户端伪造占位：任务、资源、记忆、对话图和定时任务都通过其真实 Project ID 使用普通业务接口。
- 默认项目不改变 Lumi 作为普通 Agent 的可配置能力；工作记录/灵感的只读边界属于各自会话，不能把默认项目伪装成这些会话的授权项目。

## 实现边界

后端使用 `DefaultProjectID(computerID)` 的稳定 ID，在已有本机身份初始化事务中幂等插入。`is_default` 是按 ID 和所属 Computer 得到的只读投影，不按名称推断，也不接受客户端伪造。所有权验证先于受保护项目的删除/改名判断。

该行为不修改 SQL 基线、不做旧库结构迁移、不清理数据；已有有效库首次使用此构建新增缺少的默认项目，并在同一身份初始化事务内，仅精确匹配真实受保护项目的旧名称「不使用项目」改为「默认项目」。实际改名只更新一次版本与时间，原 ID、说明、遗留 `projects.theme` 列、普通同名项目及业务数据不变；重启不重复修改。

Project 创建/编辑与公开 API 不再包含 `theme`。SQLite 物理旧列仅在新建项目时写入固定遗留占位以满足既有 schema，读取/更新不再参与配色，不为移除项目配色修改基线、迁移或重置旧列。全局配色与旧用户偏好的只读投影见 [全局外观与配色](APPEARANCE.md)。

前端项目选择由当前窗口的 `sessionStorage["teamva-selection"]` 保存；localStorage 只保留 Computer 选择。存储不可用时，内存选择仍有效，不能承诺跨刷新保存。默认名称按用户指定的中文显示，不随界面语言翻译；标记与说明提供九语。

概览不提供默认项目标题的行内编辑，管理弹窗名称只读、隐藏删除操作；回调与 mutation 也拒绝默认删除。服务端 `403 protected_project` 为最终保护，不依赖按钮隐藏。
